# Source control

When committing code, include a list of all prompts between now and the last commit.
Don't include prompts related to git (e.g. commit, push, pull).

If known, replace "Prompts" with the coding agent and model, e.g. `OpenAI Codex (v0.149.0), gpt-5.6-sol xhigh:`

Template:

```

Commit title

- changed feature 1
- changed feature 2

Prompts:

> Prompt 1
> Prompt 2

```
