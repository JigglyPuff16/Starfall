# Starfall: Endless

Run the game from this folder with Python:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Open it on this computer at:

```text
http://localhost:8000
```

Or, from another device on the same network, use this computer's LAN address:

```text
http://192.168.99.14:8000
```

Use `WASD` or the arrow keys to fly, hold `Space` to fire, and press `P` to pause.
